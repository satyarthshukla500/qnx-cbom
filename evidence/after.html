  1. ▲ WARN QCB-004 Key or certificate uses a quantum-vulnerable algorithm /data/var/ssh/ssh_host_ed25519_key

    Evidence

    Fix. Plan a move to ML-DSA (FIPS 204) or SLH-DSA for signing keys once your signing path supports them. OpenSSL 3.5 can generate ML-DSA keys. Until then keep RSA at 3072 bits or more.

  4. ▲ WARN QCB-005 qcrypto sends all algorithms to a plug-in without post-quantum algorithms /proc/boot/qcrypto.conf

    Evidence

    • /proc/boot/qcrypto.conf: openssl-3 tags=* (all algorithms go to this plug-in)
    • /proc/boot/qcrypto-openssl-3.so: contains no ML-KEM/ML-DSA names
    Fix. No qcrypto fix exists in SDP 8.0.6: its API has no key-encapsulation type (see evidence/T2-qcrypto-plugin.txt). Use OpenSSL 3.5 directly for post-quantum key exchange.

    Source: https://www.qnx.com/developers/docs/8.0/ (read 2026-11-23)

    Not verified:

    • Whether a later QNX release adds ML-KEM or ML-DSA to qcrypto.
    • The QNX documentation page was not read for this rule; the claim rests on the SDK headers (evidence/T2-qcrypto-plugin.txt).

  6. ✔ OK QCB-002 sshd allows post-quantum key exchange /system/bin/sshd

    Evidence

    • /system/bin/sshd (OpenSSH 10.4p1) contains: mlkem768x25519-sha256, sntrup761x25519-sha512, sntrup761x25519-sha512@openssh.com.
    • /system/etc/ssh/sshd_config line 6: KexAlgorithms mlkem768x25519-sha256,curve25519-sha256@libssh.org,ecdh-sha2-nistp256,ecdh-sha2-nistp384,ecdh-sha2-nistp521,diffie-hellman-group-exchange-sha256 (explicit list)
    • A post-quantum key exchange is allowed.
    Fix. In the sshd_config of the image (the inline block in system.build) start the KexAlgorithms line with mlkem768x25519-sha256 and keep a classical fallback, for example: KexAlgorithms mlkem768x25519-sha256,curve25519-sha256@libssh.org,ecdh-sha2-nistp256. Rebuild the image and scan again.

    Source: https://www.openssh.com/txt/release-10.0 (read 2026-11-23)

    Not verified:

    • That the SSH clients you use support mlkem768x25519-sha256.
    • The OpenSSH release that first contained the algorithm (only 10.0 was read: it made the algorithm the default).
