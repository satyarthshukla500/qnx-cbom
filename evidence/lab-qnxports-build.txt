Note: the SONAME is libcrypto.so.3.5, not libcrypto.so.3, so LD_LIBRARY_PATH does not replace the image library by itself (the port is meant to live next to 3.0).
For the lab image the file was installed under the name libcrypto.so.3 in /proc/boot (demo/build_after.sh with AFTER_DIR=after-qnxports CRYPTO_SRC=libcrypto.so.3.5 SSL_SRC=none); libssl was left as in the stock image.
The port is built with assembler code (-DAES_ASM ... in the compile lines), unlike the lab 3.5.9 build.
